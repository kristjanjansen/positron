automation lane × media clip

the 2025 slider-video.vue experiment, completed — the curve's x-axis IS transport position ← XY pad
What this is. The final commit of the 2025 demo repo was an automation lane bound to a media clip by clipId. It died at one missing mapping: absolute epoch ms → a foreign media element's normalized position → pixels. There was no transport that owned a position domain, so the slider knew where it was on screen and the video knew where it was in itself, and nothing converted between them. The library has both halves now — makeLogDeck's toPos/toAtUs and transport.sync() — so here it is, running.
