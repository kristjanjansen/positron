Kujundus pildist

Every event picture below is read on a 64 pixel canvas as this page opens. From those pixels the page takes what the plan says a picture can give: a ground for the head of the event page, if all four edges are one colour and that colour is not white, lightened until the muted ink reads on it; an accent for underlines and focus rings, if the picture has a real hue, toned until it reads on white and stands apart from the ink; or the reason it gives neither, which is most of them.

Beside each picture the head of an event page is drawn in what it gave. The prose under it would stay ink on white on every event; only the head takes the ground, and the accent shows only where the page already uses one.

The Gestures graphic is typed in a serif with reversed letters. For an event whose graphic is set in a serif, the title could answer it in one. Below, the same head over the derived ground with the title in three serifs, each self hosted and subset for Š and Ž. Sixty four pixels cannot tell a serif from a sans, so this is not detected: in the editing form it is one checkbox beside the picture, Graafika kiri on seriifidega, and the migration script leaves it off.
